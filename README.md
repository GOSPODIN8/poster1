# Прогрев-бот для @adrian_trape

Автоматически публикует посты про дропшиппинг в канал **@adrian_trape** 5 раз в день,
каждый пост мягко прогревает подписчиков ко вступлению в закрытый клуб через бота
**https://t.me/clubBXOD_bot**.

## Как работает

1. По расписанию (по умолчанию: 09:00, 12:30, 16:00, 19:00, 22:00 МСК) бот:
   - просит Gemini придумать тему и написать пост (гайд/лайфхак/разбор ниши)
   - генерирует картинку под тему через Imagen
   - публикует пост в канал (фото + подпись, либо просто текст, если картинка не сгенерировалась)
2. Каждый пост заканчивается разным по стилю мягким призывом вступить в закрытый клуб — Gemini сам варьирует формулировку, чтобы не было ощущения спама
3. `/post_now` (только для ADMIN_ID) — опубликовать пост прямо сейчас, не дожидаясь расписания (удобно для теста)
4. `/stats` (только для ADMIN_ID) — статистика: сколько постов вышло успешно/с ошибками, последние попытки

## Настройка перед запуском

1. Токен бота — у @BotFather
2. Бот должен быть **администратором** канала @adrian_trape с правом публиковать посты
3. Ключ Gemini API — https://aistudio.google.com/apikey
4. Свой Telegram ID — через @userinfobot (это ADMIN_ID)

## Деплой на Railway

1. Новый проект → загрузи код (или подключи GitHub-репозиторий)
2. Variables:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `GEMINI_API_KEY`
   - `CHANNEL_USERNAME` — можно не менять, уже стоит `@adrian_trape`
3. Railway сам поставит зависимости из `requirements.txt` и запустит `python bot.py`

## Что можно поменять

- **Расписание** — список `POST_TIMES_MSK` в `config.py`
- **Стиль/длина постов, тон призыва** — промпт `TEXT_PROMPT_TEMPLATE` в `content_generator.py`
- **Стиль картинок** — промпт `IMAGE_PROMPT_TEMPLATE` там же

## Если генерация картинки не удалась

Бот не падает — просто публикует пост без фото, только текстом, и это видно в `/stats`.
